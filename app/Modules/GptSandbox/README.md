# GPT · тестовий чат

Приватний тестовий агент OpenAI з правилами робочого агента Claude та окремо погодженим серверним оформленням GPT. Реалізація Claude не змінюється. Промпт, каталог і тексти GPT лежать у цьому модулі; сервіси Claude під час роботи GPT не викликаються.

## Промпт і магазин

`Application/PromptBuilder.php` зберігає правила магазину, а погоджене оформлення винесене в `Application/CheckoutProtocol.php`. Доступні сім інструментів: `get_product`, `send_photos`, `ask_delivery_details`, `update_order`, `send_payment_details`, `complete_order`, `escalate_to_manager`.

Чинна інструкція магазину читається з `ai_settings.system_prompt` без її зміни. За кількох магазинів власник обирає потрібний у налаштуваннях GPT; для одного магазину вибір автоматичний. Якщо локальна копія не містить налаштувань, застосовується стандартне правило магазину. `Context/assortment.md` до промпту не додається.

`CatalogProtocol` перетворює схеми інструментів у strict `parameters` Responses API, включно з об’єктами всередині nullable-масивів. Необов’язкові значення допускають `null`; зайві поля заборонені. Ключ OpenAI окремий і зашифрований, модель залишається обраною власником.

## Серверна чернетка та оплата

Через `update_order` модель передає лише `product_id`, точний `size`, `qty`, дані доставки та вибраний спосіб оплати. Невідомі дані — `null`, вони залишають попередні значення. `CheckoutPricing` читає поточні ціни й залишки, перевіряє активність товару та розміру, точний збіг підпису, сукупну кількість повторених позицій і наявність. `Money` рахує цілими копійками. Ціни й суми від моделі не приймаються.

Три способи оплати:

- `cod` — вся сума при отриманні;
- `full` — повна оплата на картку/ФОП;
- `deposit` — 100 грн передоплати, решта при отриманні.

Агент пропонує всі варіанти під час оформлення та приймає вже зроблений вибір без повторного питання. Для суми до 100 грн включно доступні `full` і `cod`. У заявці зберігаються серверні `total`, `pay_now`, `pay_on_delivery` та суми позицій. Vue показує їх без власного перерахунку.

`send_payment_details` і `complete_order` не приймають сум чи товарів, а використовують серверну чернетку. Картка й IBAN надсилаються окремими повідомленнями. Зміна кошика чи оплати скидає старі реквізити та квитанцію; незмінний запит не дублює реквізити. Після зміни серверної ціни потрібні нове повідомлення покупця й `update_order(confirm_total=true)`; повторний виклик у тому самому ході не обходить перевірку.

Перед завершенням перевіряються доставка, спосіб оплати й поточна наявність. Для `full`/`deposit` потрібне фото саме квитанції в новому повідомленні після актуальних реквізитів. Текстове «оплатив» та попереднє фото не підходять. Квитанція фіксується як `provided_unverified`, без перевірки зарахування банком.

Після останнього API-виклику наявність і ціни перевіряються ще раз перед збереженням успіху. Помилка залишає повідомлення й вкладення доступними для повтору. Після завершення додається фінальний текст магазину й агент зупиняється в цій розмові. Ескалація використовує текст магазину й паузу 12 годин.

## Ізоляція

Сторінка `/settings/gpt-sandbox` доступна лише активному власнику. Дії зберігаються в приватній тестовій заявці без надсилання реальним клієнтам, створення замовлення CRM чи резервування товару. Перевірка залишку не є резервом. Заявка й платіжні повідомлення зашифровані та записуються лише після успішної відповіді.

Історія API містить до 20 реплік і повні reasoning/function-call елементи; фото додаються з трьох останніх вкладень. Поточна серверна чернетка передається окремим контекстом, щоб суми й вибрані позиції не залежали від давності повідомлень.

## Запуск і перевірка

```sh
php artisan migrate --path=app/Modules/GptSandbox/Database/migrations
npm run build:gpt-sandbox
php artisan test --compact tests/Feature/GptSandbox
npm test -- resources/js/gpt-sandbox/SandboxPage.spec.js
```

Тести перевіряють незмінені правила магазину, точні суми й передоплату 100 грн, наявність, зміну ціни, квитанцію, ескалацію, ізоляцію та помилки API. Використовуються підставні HTTP-відповіді й окрема SQLite; платних API-запитів у тестах немає.

## Локальна копія каталогу

```sh
php artisan gpt-sandbox:import-catalog /absolute/path/catalog.json
php artisan gpt-sandbox:import-catalog /absolute/path/photo-purposes.json --photo-purposes-only
```

Імпорт дозволений лише в `local`/`testing` із SQLite. Перша команда потребує порожнього каталогу; друга оновлює лише приватні призначення фото. Ключі й тестові чати не змінюються. Фото лежать у приватному `gpt-sandbox/catalog-media/ai-gallery`, метадані — в `gpt-sandbox/catalog-source.json`. Ціни й залишки копії відповідають часу експорту; автоматичної синхронізації немає.
