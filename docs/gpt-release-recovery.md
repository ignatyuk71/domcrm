# Відновлення погоджених змін GPT — 05.11.2026

Попередні оновлення GPT-чату та коментарів були застосовані вручну до релізу сервера, але залишилися поза `main`. Штатне розгортання з Git повернуло старі файли. Відновлення включає всі погоджені залежності, тести й документацію до `main`, щоб наступний штатний реліз містив той самий функціонал.

## Відновлений набір

- Буфер серії повідомлень від 30.10: окреме вікно тиші GPT, збирання всієї серії, захист від застарілих відповідей, контроль фактичної доставки частин оформлення.
- Вкладення від 30.10: фото й контекст дописів, перевірка MIME, дублікати, пояснення недоступних зображень.
- Коментарі v1/v2 від 02.11: окреме рішення GPT, актуальні серверні ціни, збереження джерела звернення, прив'язка до чату, картки оператора.
- Згортання картки джерела від 02.11: вузька смужка за замовчуванням, розкриття деталей, збереження стану під час polling.
- Промпт v4 від 03.11: узгоджені уточнення моделі, категорії та пріоритет явного вибору клієнта.

Runtime-файли звірені з контрольними сумами погоджених пакетів. `GptHistory` містить їхній остаточний погоджений склад, а `GptInboxAgent` поєднує цей склад із чинним надсиланням фото перед текстом і `DeliveryImage`. Інші реалізації агентів не замінюються.

## Дані та чинні налаштування

Перед відновленням підтверджено наявність nullable-колонок контексту, зареєстрованої міграції та 16 історичних записів із контекстом. Відновлення коду не повторює старі приватні відповіді й не переносить історію з резервних копій. Використовується чинна спільна база та той самий shared `.env`.

До зміни не включені модель, API-ключі, промпти магазинів у базі, числові налаштування, список моделей та нова верстка налаштувань. Чинні оптимізовані копії зображень і порядок фото → текст збережені. Окремий таймер GPT на 4 секунди відновлено саме у раніше погодженому вигляді; глобальне поле паузи лишається окремим наявним налаштуванням.

## Перевірка

Локально пройшли 1105 PHP-тестів із 10754 перевірками. Окрема DOM-перевірка карток пройшла: екранування, посилання, історичні ціни, невизначені товари, збереження DOM-чернеток, фокусу й виділення, polling, стан надсилання та помилки toast. Зовнішні API у цих тестах підмінені або заблоковані.

Штатне розгортання проходить повні CI-перевірки SQLite, MySQL і frontend. Після розгортання слід звірити SHA релізу та цільових файлів, доступність історичних карток у read-only перевірці й незмінність налаштувань. Тест не повинен викликати контролер читання повідомлень, створювати замовлення чи надсилати повідомлення покупцям.
