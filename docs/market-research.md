# Аналіз ринку: пробна Meta Ad Library

Сторінка `/market-research`, пункт меню **Маркетинг → Аналіз ринку**, доступна лише власнику. Відкриття сторінки не запускає зовнішніх запитів. Кнопка перевірки читає `id,name` обраної сторінки Facebook та запитує до 6 активних оголошень через `ads_archive`. Статус підключення чату, токени та вебхуки не змінюються; повідомлення не надсилаються.

Для проби можна використати наявний токен сторінки. Meta може відхилити його: чинний доступ до чату не підтверджує доступ до Ad Library. Для окремого доступу виконайте кроки на [Meta Ad Library API](https://www.facebook.com/ads/library/api/) та задайте токен користувача на сервері:

```dotenv
META_AD_LIBRARY_ACCESS_TOKEN=
```

Після зміни змінних середовища оновіть кеш конфігурації штатним процесом розгортання (`php artisan config:cache`, якщо кеш використовується). Версія Graph API береться з наявного `META_GRAPH_VERSION`.

Пробний API-пошук комерційної реклами працює для Польщі, Німеччини та Чехії. Для України сторінка пропонує прямий пошук на сайті Meta, без спроб отримати неповну вибірку через API. Порожня успішна відповідь підтверджує доступ, але не доводить відсутність реклами. Оголошення не є рейтингом продажів або доказом прибутковості товару.

Токени передаються тільки з сервера через заголовок Authorization. Відповідь містить дозволені поля й посилання, побудовані за ID оголошення; сирі `paging` та `ad_snapshot_url` не передаються. Діагностичні помилки показують код Meta та очищене повідомлення. Запити обмежені до 6 на хвилину для авторизованого власника.

Перевірка: `php artisan test --filter=MarketResearchTest` та `npm test -- resources/js/crm/pages/marketing/MarketResearchPage.spec.js`.
