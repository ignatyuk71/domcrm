# Перемикання агентів у месенджері

Власник відкриває **Налаштування → AI-агент → Канали AI**:

1. Зберігає ключ GPT та точний ID доступної моделі.
2. Вмикає GPT API, перевіряє підключення кнопкою завантаження моделей.
3. Обирає типового агента. Він використовується для коментарів і чатів без власного вибору.
4. За потреби вимикає Claude API. Після цього нові виклики Claude блокуються, включно з підсумками та перевіркою ключа. Автоматичного переходу на інший API немає.

У панелі окремого чату власник може закріпити Claude або GPT. Незавершене оформлення та активна генерація блокують зміну агента цього чату. Скидання памʼяті прибирає чернетку оформлення, зберігаючи повідомлення. Поточну історію повідомлень обидва агенти читають незалежно.

Початково активний Claude; GPT вимкнено. Чинні ключ і налаштування Claude залишаються у `ai_settings`, GPT має окремий зашифрований ключ у `ai_channel_settings`. Дані тестового стенда не переносяться до робочого каналу автоматично. Запит, уже надісланий провайдеру перед вимкненням, може бути оплачений; наступні запити та застарілі відправлення блокуються.

## Каталог та галерея

Робочий GPT читає чинні товари, варіанти, залишки, ціни, товарні лінійки та їхні звʼязки з галереєю без імпорту. Зображення беруться з `public/ai-gallery`, що на сервері посилається на спільне сховище. Товарні фото, колажі та пояснення розміру розрізняються; неіснуючі файли та звʼязки поза лінійкою не пропонуються.

Локальний SQLite-знімок дозволений лише маршрутам тестового стенда в оточенні `local`/`testing`, коли метадані вказують саме на поточну базу. Робочий канал його не використовує. Команда `gpt-sandbox:import-catalog` заборонена в production.

## Оформлення та повтори

GPT рахує суми й перевіряє наявність на сервері. Варіанти оплати: при отриманні, повністю або 100 грн передоплати з рештою при отриманні. Фото квитанції позначається як неперевірене; зарахування коштів агент не підтверджує. Завершена заявка потрапляє у чинну панель «Замовлення від ШІ», остаточне оформлення виконує менеджер.

Підготовлена відповідь зберігається зашифрованою в `gpt_inbox_replies`. Повтор після помилки Meta продовжує відправлення з курсора без нової генерації. Повторна джоба вже обробленого повідомлення не викликає модель. Є спільний замок на чат і контроль зміни провайдера, ручного вимкнення та нових повідомлень. Якщо зовнішня служба прийняла повідомлення, але не повернула відповідь через обрив зʼєднання, її API не дає абсолютної гарантії від дубля.
