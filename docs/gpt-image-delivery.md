# Доставка фото GPT

Нові відповіді GPT надсилаються у порядку «фото по черзі → текст». Для кожного фото очікується успішна відповідь Meta API перед наступним елементом. Це не є підтвердженням відображення зображення на телефоні покупця.

Порядок фіксується в payload відповіді. Наявні черги з `text_first=true` та їхні курсори не переставляються. Після помилки повтор продовжується з невдалого фото без нової генерації GPT. Збережено чинний захист від застарілих повідомлень, втручання оператора й вимкнення агента.

`App\Services\Ai\Gpt\DeliveryImage` готує окремі JPEG-копії для вихідних фото GPT. Початкові файли, рядки галереї, ID фото та реалізація Claude не змінюються. У повідомлення записуються фактичний URL копії та початковий `ai_photo_id`, щоб історія й захист від повторів визначали правильний товар.

Параметри: довша сторона до 1600 px, JPEG 84/80/76, м’яка ціль 350 KiB без додаткового зменшення сторін заради ваги. Копія використовується, якщо вона щонайменше на 10% легша. Готові невеликі файли, `size_guide`, GIF, прозорі зображення та джерела з ICC/CMYK передаються оригінальними. Перед декодуванням перевіряються формат, обсяг, розміри й запас пам’яті. Збій оптимізації повертає початковий URL і не зупиняє доставку відповіді.

Кеш розміщується в `public/ai-gallery/gpt-delivery/` з ключем SHA-256 вмісту, шляху, параметрів і версії. Запис атомарний; перед використанням перевіряються JPEG, розміри й завершеність файла. Після зміни алгоритму треба підняти версію кешу. Нові фото оптимізуються під час першого надсилання, наступні використовують кеш.

На проді `public/ai-gallery` посилається на персистентний `shared/public/ai-gallery`. Каталог `gpt-delivery` має бути доступним на запис і вебпроцесу, і працівникам черги; поточне налаштування — `deploy:www-data`, 2775, файли 0644. Розмірні таблиці залишаються в початковій якості.

Перевірки: `GptImageDeliveryTest`, `GptDeliveryImageTest`, регресійний `AiChannelsTest`. Зовнішні API-запити в тестах підмінено. Перевірки не надсилають повідомлень живим клієнтам і не витрачають токени GPT.

Зміна має бути включена в `main` і розгортатися штатним workflow після Tests (sqlite) та Tests (mysql). Разова заміна файлів у `current` не є постійним розгортанням: наступний реліз відновить вміст Git-коміту.
