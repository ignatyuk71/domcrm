# Демонстраційна квитанція

Один PDF міжнародної доставки використовується командою `php artisan expenses:demo`.
Документ явно позначений як зразок і не підтверджує реальної оплати.
Команда типово працює тільки в середовищі `local` з локальною базою.
Для ручного запуску на сервері потрібен явний `--force`; автоматичного запуску немає.
Наявні демозаписи не дублюються.

Приватна копія зберігається у `storage/app/private/expenses/receipts/demo`.
Перегляд і завантаження доступні лише власнику.
