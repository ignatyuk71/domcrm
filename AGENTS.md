# Правила проєкту DOM-CRM

- Спілкування та коментарі в коді — українською.
- Для інформаційних подій (успіх, помилка, попередження, результат збереження/редагування/видалення) використовуйте **toast**, а не inline alert-блоки, постійні зелені написи або `window.alert()`.
- Перевикористовуйте `resources/js/crm/components/ui/Toast.vue` та `resources/js/crm/composables/useToast.js`. Не мігруйте всі старі сторінки поза поточним завданням.
- Зберігайте зміст і контекст помилки; підсвічуйте відповідні поля, не стирайте чернетки. Помилки не повинні автоматично зникати чи перекриватися повідомленням успіху; залишайте доступну дію повтору/виправлення.
- Успішне автозбереження групуйте в одне коротке повідомлення після підтвердження сервера. Не показуйте «Збережено» при звичайному завантаженні сторінки.
- Toast не замінює обов’язкове підтвердження незворотного видалення чи браузерний захист від виходу з незбереженими даними. Для руйнівних дій потрібне окреме явне підтвердження.
- Табель `/work-time` — лише введення годин і денних сум, вибір періоду та підсумки. Не повертайте сюди додавання/редагування/видалення працівників, зарплатні модальні вікна чи клікабельні імена. Керування працівниками та зарплатний звіт розташовані на `/settings/work-payroll` лише для власника.
- Приховані кнопки не є авторизацією. Зберігайте серверні обмеження доступу; не відкривайте зарплатні дані операторам без окремої вказівки власника.
